# onX Hunt Growth Audit

**Live → https://eddieatadapty.github.io/onx-hunt-flow-rebuild/**

Five ideas to turn more onX Hunt users into subscribers, each built into a clickable version of onX Hunt's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Ask the one question their ad left open | +10–15% CR to purchase |
| 02 | Show the thing the ad promised before the price | +5–15% CR to purchase |
| 03 | A different membership screen for each promise | +10–15% ARPU |
| 04 | Answer ✕ with what that hunter needs | +5–10% CR from closers |
| 05 | Offer onX SOS once, right after they join | +5–10% ARPU |

Every price, rating and feature comes from onX Hunt's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for onX Hunt. They overlap, so they don’t add up.

Static single page, no build step: `python3 -m http.server`.
